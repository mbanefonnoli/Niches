# Niche: IoT and electronics hardware makers

Use the `studio-core` skill for the workflow and `niche-iot-hardware` for market knowledge.

- Prospects: `prospects.csv` (target 20, best 10 get samples).
- Learnings across clients: `notes.md`.
- Clients: `clients/<client>/` — create with `python scripts/new-client.py iot-hardware "<Client Name>"` from the repo root.

Default ad language: English. Specs, certifications and test conditions come only from the client's datasheet or docs in `assets/`.
