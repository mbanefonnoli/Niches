# Niche: local retail and gift shops

Use the `studio-core` skill for the workflow and `niche-local-retail` for market knowledge.

- Prospects: `prospects.csv` (local shops in Constanța first).
- Learnings across clients: `notes.md`.
- Clients: `clients/<client>/` — create with `python scripts/new-client.py local-retail "<Client Name>"` from the repo root. First client: `clients/lighthouse-cafe/`.

Default ad language: Romanian. This niche is a portfolio and testing ground; keep packages small and production cheap.
